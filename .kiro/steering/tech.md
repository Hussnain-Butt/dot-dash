# Dot-Dash — Technology

## Stack

- Static site in TypeScript, built with Vite.
- Hosted on GitHub Pages.
- Vitest for unit tests; fast-check for property-based tests.
- Web Speech API for speech output; Web Audio API for any sound feedback.
- localStorage for the user's timing profile and saved phrases.
- Service worker for offline use.

## Constraints

- No backend. No accounts. No analytics. No external API keys. No paid services. No runtime network calls.
- The whole project must cost $0 to build, host, and run.
